
### Шаг 1 — Скачивание модели YOLOv8n

#### Способ 1 — Автоматически через Python (рекомендуется)

```bash
# Обновить pip до последней версии
pip install --upgrade pip

# Установить все зависимости из файла requirements
pip install -r requirements.txt
```

Модель `yolov8n.pt` — это **nano**-вариант YOLOv8: самый лёгкий и быстрый.


```python
# Запустите Python в терминале с активированным venv
python

# Внутри интерпретатора:
from ultralytics import YOLO
model = YOLO("yolov8n.pt")  # автоматически скачает модель
exit()
```

Модель скачается автоматически (~6.2 МБ) и сохранится в текущей директории.

#### Способ 2 — Прямое скачивание через терминал

```bash
# Windows PowerShell
Invoke-WebRequest -Uri "https://github.com/ultralytics/assets/releases/download/v8.4.0/yolov8n.pt" -OutFile "yolov8n.pt"
```

### Шаг 3 — Размещение модели в проекте

После скачивания переместите файл `yolov8n.pt` в папку `Assets/Models/` 

---

### Шаг 4 - Открытие проекта в Unity

1. Запустите **Unity Hub**.
2. Нажмите **Open → Add project from disk**.
3. Выберите корневую папку репозитория `Eot-turret/`.
4. Unity начнёт импорт ассетов — дождитесь полной загрузки (может занять 2–5 минут).
5. В окне **Project** откройте сцену:
   ```
   Assets → Scenes → MainScene.unity
   ```
6. Необходимо создать базовую пластину  и задать ей размер (10X10X10)
7. Разместите префаб турели "STT_Turret (Prefab Asset)"  из папки Assests (открыта по умолчанию)
8. Разместите префаб спавнера солдат "spawner (Prefab Asset)" из папки Assests
